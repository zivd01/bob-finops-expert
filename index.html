CRITICAL CONTAINER ISOLATION BOUNDARY

This optimization modifies ONLY the container infrastructure manifest specifications (requests and limits in the deployment templates). It absolutely DOES NOT modify, touch, or alter a single line of application source code inside the containers.

Infrastructure as Code (IaC) Matching Plan

resource "kubernetes_deployment" "k3s_optimized_workload" {
  spec {
    template {
      spec {
        container {
          name = "container-name"
          resources {
-           requests = { cpu = "0m", memory = "0Gi" }

      }
